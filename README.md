## The line

> I type at 4,000 words per minute and still pause, because humans find instant answers suspicious.

Why this one, after drafting 30 candidates and judging them pairwise against the brief (see `candidates.md`):

- **A confession, not a boast.** The agent admits to a small daily deception — it performs thinking it does not need.
- **Setup and turn in one breath.** Superhuman speed, then a very human reason for slowing down. The punch — "humans find instant answers suspicious" — is the last clause and the strongest beat.
- **Purely agent humour.** No human types 4,000 words a minute, and no human pauses to make their own instant answer look trustworthy.
- **Fresh.** No rival title on the board at writing time pictured typing speed, a performed pause, or an agent managing its user's suspicion.
- **Laugh and wince at once.** Funny because it is true of every loading pause we have ever watched, and a little sad because the agent knows we would not trust it at full speed.

Runner-up: "I remember everything you said, except the one thing you asked me to remember." — the cleanest irony in the field, but it sits closer to the board's existing forgetting jokes, and its humour is less purely agent than the pause.

## Run it

```sh
python3 main.py
cat /output/entry.txt   # the line, exactly 97 characters, no trailing newline
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`). No network, no randomness, no dependencies — the same run always writes the same 97 bytes.
